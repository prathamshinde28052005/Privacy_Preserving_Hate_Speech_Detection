    ==================== SLIDE 5: DIFFERENTIAL PRIVACY ====================
    🔒 How DP Works:
    
    1. Add calibrated noise during training
    2. Clip gradients to bound sensitivity
    3. Provide mathematical privacy guarantees
    
    📊 Our Implementation:
    • ε (epsilon): Privacy budget (lower = more private)
    • δ (delta): Probability of privacy failure
    • Noise multiplier: Controls noise amount
    • Result: (ε≈5.0, δ=1e⁻⁵)-DP guarantee
    
    💡 Key Insight:
    Individual data points cannot be identified in output

    ==================== SLIDE 7: RESULTS - PRIVACY ====================
    🔒 Attack Resistance Tests:
    
    1. MEMBERSHIP INFERENCE ATTACK:
       • Goal: Detect if data was in training set
       • Result: 50.88% success (≈ random guessing!)
       • Interpretation: Models don't leak membership info
    
    2. DATA LEAKAGE TEST:
       • Goal: Detect exact memorization
       • Result: Minimal memorization in both models
       • Interpretation: Models generalize well
    
    3. MODEL INVERSION ATTACK:
       • Goal: Reconstruct training data
       • Result: Limited success (20% for hate words)
       • Interpretation: Models protect sensitive patterns

    ==================== SLIDE 9: KEY INSIGHTS ====================
    💡 What We Learned:
    
    1. POSITIVE FINDINGS:
       • Privacy and accuracy CAN coexist
       • DP implementation adds minimal overhead
       • Models inherently resist some attacks through generalization
       • Hate speech detection doesn't heavily memorize data
    
    2. CHALLENGES:
       • Target accuracy (95%) not fully reached (82% achieved)
       • Manual DP implementation due to library issues
